# FRM-Part2-Study-Tool
FRM‑Part2‑Study‑Tool Self‑built review toolkit for FRM Part 2 November 2026 exam. Built with HTML, Tailwind CSS, TypeScript, KaTeX and D3.js. All data stores locally in browser LocalStorage, no backend required.

## Features
- Knowledge base: core concepts & formulas with bilingual (CN‑EN) explanation
- Anki‑style flashcard mode for concept & formula memorization
- Knowledge graph showing relationships between chapters, concepts and questions
- Custom random quiz & mock exam with answer and detailed explanation
- Mastery tracking: mark knowledge points as Mastered / Review / Unlearned
- Wrong‑question bank, export wrong questions to Markdown / PDF
- Dark / light theme, language switch between Chinese and English

## How to use
1. Clone or download this repository.
2. Place `knowledge_base.json` and `question_bank.json` in the same folder as `index.html`.
3. Open `index.html` directly in your browser.
4. You may replace JSON files with your own structured study materials.
